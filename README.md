# Knots & Bloom

Handmade crochet shop for Knots & Bloom: catalogue, cart, checkout, wishlist, account, journal, custom orders, and a studio desk.

The studio key in this demo is `bloom`. Orders, accounts, and catalogue edits stay in the browser. Checkout does not charge a card.

Brand logo: `public/brand/logo.jpg`.
