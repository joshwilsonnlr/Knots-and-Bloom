# Knots & Bloom

This repository is the **source code** for the shop. Opening it on GitHub shows this readme, not the storefront. The website itself runs from a dev server or a host such as Vercel.

Handmade crochet shop: catalogue, cart, checkout, wishlist, account, journal, custom orders, and a studio desk.

The studio key in this demo is `bloom`. Orders stay in the browser. Checkout does not charge a card.

Instagram [@knotbloom58](https://www.instagram.com/knotbloom58/) is login-walled, so product photography in `public/products` is a stand-in until real post images are added. The brand mark is `public/brand/logo.jpg`.
